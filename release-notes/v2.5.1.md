## 한국어

로컬 번역 모델의 다운로드 검증과 번역 오류 처리를 개선하고, 앱 내부 구조와 배포 파일을 정리한 유지보수 업데이트입니다.

### 변경 사항

- 로컬 번역에 자동 조절 (시험) 옵션을 추가하고, 기존 하나씩 번역을 기본값으로 유지했습니다. 하나씩 번역도 선택한 GPU를 사용합니다. 자동 모드는 모델 전체가 CUDA GPU에 올라간 경우 메모리 여유와 자막 수를 확인합니다. 짧은 작업도 2개로 제한하지 않고, 같은 자막 표본의 처리 속도와 준비 비용에 비해 남은 작업량이 충분한지 비교합니다. 기본 표본 번역은 결과에 재사용하고, 시험 비용을 회수하기 어려운 작은 작업은 하나씩 처리합니다. 속도 비교 때문에 전체 시간이 늘어날 수도 있으며, Hy-MT2 1.8B와 7B에 같은 기준을 적용합니다. 추가 실행 공간을 만들지 못하거나 동시 처리 중 메모리가 부족하면 같은 GPU에서 개별 처리로 돌아갑니다. 로그에서 실제 장치, 동시 처리 수와 소요 시간을 확인할 수 있습니다. 여러 자막을 한 프롬프트에 합치는 방식은 아니며, 모든 작업에서 더 빠른 것은 아닙니다.
- 자막 본문에 숫자만 있는 줄이 있어도 자막 번호로 오인하지 않고 앞뒤 문장과 함께 번역합니다. 숫자만으로 된 자막은 번역하지 않으며, 자막 번호와 시간표시는 유지합니다.
- 저장 폴더와 기존 파일 처리 방식을 선택할 수 있습니다. 기본은 새 이름으로 저장하며, 건너뛰기 또는 성공한 뒤 덮어쓰기도 지원합니다. 추출 실패 시 이전 자막을 새 결과로 인식하지 않도록 했고, 자막과 설정 저장 중 쓰기 실패가 나도 기존 파일을 보존합니다.
- 여러 언어 중 일부만 실패하면 큐와 기록에 부분 완료로 표시합니다. 재시도는 이미 추출한 자막을 재사용해 실패한 언어만 처리하며, 성공하면 기존 실패 기록을 갱신합니다.
- 빈 번역 응답을 성공한 자막으로 저장하지 않도록 했습니다. 중지한 뒤 도착한 응답은 저장하지 않으며, 동시에 받는 로컬 모델도 각각 취소할 수 있습니다.
- 진단 정보 복사 버튼을 추가했습니다. 버전, 사용 가능한 가속 방식과 이번 실행의 최근 오류 분류만 복사하며 API 키, 파일 경로와 자막 내용은 제외합니다. 옆의 오류 로그 위치 열기로 실제 `errors.log`를 찾을 수 있습니다. 로그가 없으면 빈 파일을 만들지 않고 폴더를 엽니다. 원본 로그에는 개인 경로나 내용이 있을 수 있으므로 공유 전에 확인하세요.
- 복구 가능한 병렬 준비 실패나 메모리 부족은 원인과 같은 GPU에서 하나씩 재시도한다는 안내를 다섯 언어로 표시합니다. 원본 오류, 실패 단계, 모델, 실제 백엔드와 동시 처리 수를 `errors.log`에 남깁니다. 단순히 하나씩 처리가 선택된 경우는 오류로 기록하지 않으며, 재시도 성공을 보장하지는 않습니다.
- 설정을 빠르게 바꿀 때 늦게 끝난 자동 저장이 새 로컬 처리 모드나 공급자 모델을 이전 값으로 덮지 않도록 수정했습니다.
- 클라우드 모델 선택 목록과 요청 형식을 갱신했습니다. 저장된 모델 ID와 직접 입력한 모델은 유지합니다. 오래된 고정 요금과 무료 한도 안내를 정리했으며, 실제 이용 가능 여부와 요금은 공급자 계정에서 확인해야 합니다.
- Hy-MT2 1.8B와 7B 모델은 고정된 버전, 정확한 파일 크기, SHA-256으로 검증합니다. 기존 모델도 로드 전에 검사하며, 크기나 수정 시간이 바뀌지 않으면 검증 결과를 재사용합니다.
- 로컬 모델 다운로드에 이어받기, 재시도, 미러 전환을 적용했습니다. 새 파일 검증이 끝날 때까지 기존 모델을 보존하고, 교체 실패 시 복구합니다. 취소 직후 재시도가 아직 종료되지 않은 다운로드에 붙는 문제도 수정했습니다.
- MyMemory가 잘못된 입력을 403 상태와 함께 반환해도 할당량 문제로 반복 재시도하지 않습니다. 마지막 MyMemory 대체 번역에서도 지정한 원문 언어를 전달합니다.
- Windows 패키지에 CUDA 12 DLL을 배치하고 앱 내부 검색 경로에 등록해, 시스템에 CUDA를 별도 설치하지 않아도 로컬 번역의 자동 탐지에서 찾을 수 있게 했습니다.
- 최소 창 높이에서도 파일 선택 버튼과 지원 형식 안내가 잘리지 않도록 수정했습니다.
- 다섯 언어의 파일 추가, 중지, 작업 이력과 공유 모델 안내를 다듬었습니다. 일본어, 중국어, 폴란드어에 빠진 작은 목소리의 자막 누락 주의사항을 추가하고, 오타와 어색한 모델 설명, 모델 개수 표시를 수정했습니다.
- 창이 없거나 이미 종료된 경우 늦게 도착한 전사 출력과 진행 알림을 버려, 작업의 완료·오류 처리가 알림 전송 때문에 끊기지 않도록 했습니다. 자식 프로세스 정리 중 비워진 참조에 접근하던 예외도 수정했습니다. 백그라운드 작업 기능을 추가한 것은 아니며, Windows와 Linux에서는 마지막 창을 닫으면 기존처럼 앱이 종료되고 작업이 중지됩니다.
- 로그 표시에서 시간표시가 있는 전사 줄을 보존하고, 함께 들어온 상태 줄은 따로 번역합니다. 표시된 파일명과 오류 사유 안의 문구가 중복 번역되지 않도록 규칙 범위를 제한했습니다. 저장된 SRT나 실제 파일명을 바꾸는 수정은 아닙니다.
- 장치 설정이 자동일 때 GPU 모델 로드나 첫 컨텍스트 생성이 GPU 관련 오류로 실패하면 CPU로 재시도합니다. 이는 병렬 처리 실패 후 같은 GPU에서 하나씩 재시도하는 동작과 별개입니다. 실패한 모델은 명시적인 모델 해제나 앱 재시작 전까지 기억해 같은 시도를 반복하지 않습니다. 전환 이유는 열린 창의 로그에 다섯 언어로 표시하며, 창이 없을 때의 알림은 저장하거나 다시 표시하지 않습니다.
- DeepL 계정별 요금제 안내를 5개 언어로 수정했습니다. 오프라인 사용 전 모델 다운로드가 필요하다는 설명도 보완했습니다.
- 앱 코드를 `src/` 아래 역할별로 분리했습니다. Windows 배포물에서 Linux 라이브러리와 실행 시 사용하지 않는 설치 스크립트를 제외했습니다. 개발 설치에 필요한 `scripts/postinstall.js`는 그대로 유지됩니다.

### 사용 안내

Windows에서는 `WhisperSubTranslate-v2.5.1-win-x64.zip`을 새 폴더에 풀고 `WhisperSubTranslate.exe`를 실행하세요. 기존 포터블 데이터를 옮길 경우 앱을 종료하고 `portable-data` 폴더를 백업한 뒤 복사하세요.

whisper.cpp는 v1.9.1을 유지합니다. 로컬 번역 모델이 손상되었거나 이 버전에서 지정한 파일과 다르면 무결성 검사가 거부하므로 해당 모델을 다시 다운로드해야 합니다.

Linux와 macOS는 README의 소스 실행 안내를 따르세요. 이번 준비 과정에서 확인한 Windows 앱 시작, GPU 감지, 테스트 사운드 확인은 모든 GPU의 실제 전사나 로컬 번역 성능 검증을 뜻하지 않습니다. 특히 Linux에서 만든 Windows 패키지는 Windows 전용 선택적 의존성이 빠질 수 있어 공식 배포용으로 간주하면 안 됩니다.

## English

This maintenance update improves local translation model downloads and translation error handling, and reorganizes the application and packaged files.

### Changes

- Local translation adds Automatic (experimental), keeping One at a time as the default. One at a time also uses the selected GPU. With full CUDA offload, Automatic checks memory and compares candidate speeds on the same subtitle sample, with no fixed two-worker limit for short jobs. Baseline translations are reused; small jobs skip probes that cannot repay their cost. Sampling can still increase total time. Hy-MT2 1.8B and 7B use the same policy. Failed extra-context allocation or parallel memory errors return to one at a time on the same GPU. Logs show the actual backend, worker count, and elapsed time. Cues are not combined into one prompt, and a speedup is not guaranteed for every workload.
- Number-only lines inside subtitle dialogue are translated with the surrounding sentence instead of being mistaken for cue indices. Numeric-only cues remain untranslated, and cue indices and timestamps are preserved.
- Choose an output folder and save under a new name (the default), skip existing files, or replace them after success. Failed extraction no longer accepts an old SRT as its result. Subtitle and settings writes preserve the previous file if writing fails.
- Partially successful translations are marked in the queue and history. Retries reuse the extracted SRT and process only failed languages, updating the original history entry after success.
- Empty translation responses are rejected instead of saved as successful subtitles. Responses received after stopping are not saved, and concurrent local-model downloads can be cancelled independently.
- Added diagnostic copying for versions, backend availability, and the latest error category in the current session. API keys, paths, and subtitle text are excluded. The adjacent Show error log in folder action reveals the actual `errors.log`, or opens its folder without creating an empty file. Review raw logs for private paths or content before sharing.
- Recoverable parallel setup or memory failures now explain the cause and same-GPU, one-at-a-time retry in all five languages. `errors.log` retains the original error, failure stage, model, backend and worker counts. Normal one-worker selection is not logged as an error, and a retry notice does not guarantee success.
- A delayed settings autosave no longer overwrites a newer local processing mode or provider model with an older value.
- Refreshed cloud model presets and request formats while preserving saved and custom model IDs. Removed stale fixed-price and free-quota guidance. Availability and pricing depend on the provider and account.
- Hy-MT2 1.8B and 7B models use pinned revisions, exact file sizes, and SHA-256 verification. Existing models are checked before loading; results are reused while size and modification time remain unchanged.
- Local model downloads now use shared resume, retry, and mirror fallback logic. The previous model stays intact until the replacement is verified and is restored if installation fails. Immediate retries also wait for the cancelled transfer to finish.
- MyMemory permanent input errors returned with status 403 no longer trigger quota retries. The final MyMemory fallback now receives the requested source language.
- Windows packages include CUDA 12 runtime DLLs and register the bundled directory in the app's search path, allowing local translation to detect CUDA without a separate system installation.
- File selection and supported-format labels remain visible at the minimum window height.
- Clarified file input, stop, history, and shared-model messages in all five languages. Restored missing quiet-speech warnings in Japanese, Chinese, and Polish, and corrected typos, model descriptions, and model-count messages.
- Drop late transcription output and progress notifications when their window is absent or destroyed, so notification errors do not interrupt completion/error handling. Fixed a null-reference exception in child-process cleanup. This does not add background queue processing: closing the last Windows/Linux window still quits the app and stops work.
- In the log display, preserve timestamped transcript lines and localize status lines separately, including mixed chunks. Restrict status rules so phrases inside displayed filenames and error details are not translated again. This does not modify saved SRT files or actual filenames.
- With the device set to Automatic, GPU-related failure while loading a model or creating its first context can trigger a CPU retry. This is separate from retrying parallel work one at a time on the same GPU. The failed model is remembered until explicit unload or app restart to avoid repeated GPU attempts. The reason is shown in all five languages while a window is open; notices without a live window are not queued for replay. This does not establish 7B performance on a 6GB GPU.
- Updated DeepL account-plan guidance in all five languages and clarified that offline use requires an initial model download.
- Split application code into modules under `src/`. Windows packages exclude Linux libraries and the installer-only script. `scripts/postinstall.js` remains available for development and dependency installation.

### Usage

On Windows, extract `WhisperSubTranslate-v2.5.1-win-x64.zip` into a new folder and run `WhisperSubTranslate.exe`. If moving portable data, close the app and back up the `portable-data` folder before copying it.

whisper.cpp remains at v1.9.1. Damaged local translation models, or files that differ from the pinned model, will fail verification and need to be downloaded again.

Linux and macOS users should follow the README's source setup instructions. Windows startup, GPU detection, and sample-audio checks during preparation do not verify real transcription or local translation on every GPU. Windows packages cross-built on Linux may omit Windows-only optional dependencies and must not be treated as official release builds.

## 日本語

ローカル翻訳モデルのダウンロード検証と翻訳エラー処理を改善し、アプリ内部と配布ファイルを整理したメンテナンス更新です。

### 変更点

- ローカル翻訳に自動（試験的）を追加し、従来の個別処理を既定のままにしました。自動ではモデル全体をCUDA GPUに配置できる場合、空きメモリと字幕数を確認します。個別処理も選択したGPUを使用します。短い処理を2件に固定せず、同じ字幕サンプルの速度と準備時間を回収できる残りの作業量から同時処理数を選びます。基準の翻訳結果は再利用し、小さな処理では比較を省きます。比較で合計時間が増える場合もあります。Hy-MT2 1.8Bと7Bに同じ基準を適用します。追加の実行領域の確保に失敗した場合や同時処理中のメモリ不足では、同じGPUで個別処理に戻ります。ログで実際のバックエンド、同時処理数、所要時間を確認できます。複数の字幕を1つのプロンプトにまとめる方式ではなく、すべての処理が速くなる保証はありません。
- 字幕本文の数字だけの行を字幕番号と誤認せず、前後の文と一緒に翻訳します。数字のみの字幕は翻訳せず、字幕番号とタイムスタンプを保持します。
- 保存先フォルダーと既存ファイルの扱いを選べます。既定は別名保存で、スキップと成功後の上書きにも対応します。抽出失敗時に古いSRTを結果として扱わず、字幕や設定の書き込みに失敗しても既存ファイルを保持します。
- 一部の言語だけ失敗した場合はキューと履歴に部分完了を表示します。再試行では抽出済みSRTを使い、失敗した言語だけを処理して元の履歴を更新します。
- 空の翻訳応答を正常な字幕として保存しません。停止後に届いた応答も保存せず、同時にダウンロード中のローカルモデルは個別にキャンセルできます。
- 診断情報のコピーボタンを追加しました。バージョン、利用可能な高速化方式、今回の実行中の最新エラー分類のみを含み、APIキー、パス、字幕本文は含みません。隣のボタンから実際の `errors.log` の場所を開けます。ログがまだない場合は空のファイルを作らず、フォルダーのみを開きます。共有前に個人情報を含むパスや内容がないか確認してください。
- 復旧可能な並列処理の準備エラーやメモリ不足では、原因と同じGPUで1件ずつ再試行する旨を5言語で表示します。元のエラー、失敗段階、モデル、バックエンド、同時処理数を `errors.log` に記録します。通常の選択で1件ずつ処理する場合はエラー扱いせず、再試行の成功も保証しません。
- 設定を素早く変更した際、遅れて完了した自動保存が新しいローカル処理方式やプロバイダーモデルを以前の値で上書きしないようにしました。
- クラウドモデルの候補とリクエスト形式を更新しました。保存済みや直接入力したモデルIDは維持します。古い固定料金や無料枠の説明を整理しました。利用可否と料金はプロバイダーとアカウントによって異なります。
- Hy-MT2 1.8Bと7Bは固定リビジョン、正確なファイルサイズ、SHA-256で検証します。既存モデルも読み込み前に確認し、サイズと更新日時が変わらなければ検証結果を再利用します。
- ローカルモデルのダウンロードに再開、再試行、ミラーへの切り替えを適用しました。新しいファイルの検証が終わるまで既存モデルを保持し、置き換えに失敗した場合は復元します。キャンセル直後の再試行も転送の終了を待ちます。
- MyMemoryが入力エラーを403とともに返した場合、利用枠の問題として再試行しません。最後のMyMemoryへの切り替えでも指定した原文の言語を渡します。
- WindowsパッケージにCUDA 12 DLLを同梱し、アプリの検索パスに登録します。システムにCUDAを別途インストールしなくても、ローカル翻訳の自動検出で認識できます。
- 最小ウィンドウ高でもファイル選択ボタンと対応形式の表示が切れないよう修正しました。
- 5言語のファイル追加、停止、履歴、共有モデルの案内を見直しました。日本語、中国語、ポーランド語に小さな声の字幕が抜ける場合の注意事項を追加し、誤字やモデル説明、モデル数の表示を修正しました。
- ウィンドウが存在しないか破棄済みの場合、遅れて届いた転写出力と進捗通知を破棄し、通知エラーが完了・エラー処理を妨げないようにしました。子プロセスの終了処理で発生するnull参照例外も修正しました。バックグラウンド処理の追加ではなく、WindowsとLinuxでは最後のウィンドウを閉じると従来どおりアプリが終了し、処理が停止します。

## 中文

本次维护更新改进了本地翻译模型的下载验证和翻译错误处理，并整理了应用代码与打包文件。

### 变更

- 本地翻译新增自动（实验）选项，默认仍为逐条处理。模型完全加载到CUDA GPU时，自动模式根据可用内存和字幕数量进行选择。逐条处理也使用所选GPU。短任务不固定为2条，而是用相同字幕样本的实测速度和剩余任务能否抵消准备成本来选择并发数。基准翻译会复用于输出，小任务可跳过比较。比较仍可能增加总耗时。Hy-MT2 1.8B和7B采用相同规则。额外上下文分配失败或并行处理内存不足时，在同一GPU上恢复逐条处理。日志显示实际后端、并行数量和耗时。不会将多条字幕合并到同一提示词中，也不保证所有任务都更快。
- 字幕正文中仅含数字的行不再被误认为字幕序号，而是与前后文本一起翻译。纯数字字幕不翻译，字幕序号和时间戳保持不变。
- 可选择输出文件夹及已有文件的处理方式：默认另存为新名称，也可跳过或成功后覆盖。提取失败时不再把旧SRT当作新结果，字幕或设置写入失败时保留原文件。
- 部分语言失败时，队列和历史记录显示部分完成。重试复用已提取的SRT，仅处理失败的语言，并在成功后更新原记录。
- 不再将空翻译响应保存为成功字幕，停止后收到的响应也不会保存。同时下载的本地模型可分别取消。
- 新增诊断信息复制按钮，仅包含版本、可用的加速方式和本次运行中最近的错误分类，不包含API密钥、路径或字幕内容。旁边的按钮可以打开实际 `errors.log` 的位置。尚无日志时只打开文件夹，不创建空文件。分享前请检查日志中的私人路径或内容。
- 可恢复的并行准备错误或内存不足会以五种语言说明原因，并提示在同一GPU上逐条重试。`errors.log` 会记录原始错误、失败阶段、模型、后端及并发数量。正常选择单线程处理不会记为错误，重试提示也不保证成功。
- 修复了快速更改设置时，延迟完成的自动保存将新的本地处理模式或服务商模型覆盖为旧值的问题。
- 更新了云端模型选项和请求格式，保留已保存及自定义的模型ID。清理了过时的固定价格和免费额度说明。可用性和费用取决于服务商及账户。
- Hy-MT2 1.8B 和 7B 使用固定修订版本、精确文件大小和 SHA-256 验证。现有模型也会在加载前检查；大小和修改时间不变时复用验证结果。
- 本地模型下载采用断点续传、重试和镜像切换。新文件验证完成前保留旧模型，替换失败时恢复旧文件。取消后立即重试会等待原传输结束。
- MyMemory 同时返回 403 和永久输入错误时，不再按配额问题反复重试。最后切换到 MyMemory 时也会传递指定的源语言。
- Windows 包包含 CUDA 12 DLL，并将其目录加入应用自身的搜索路径，让本地翻译无需另行安装系统 CUDA 即可自动检测到运行库。
- 修复最小窗口高度下文件选择按钮和支持格式提示被裁切的问题。
- 改善五种语言的文件添加、停止、历史记录和共享模型说明。补充日语、中文和波兰语中缺失的低音量语音字幕遗漏提示，并修正错别字、模型说明和模型数量显示。
- 窗口不存在或已销毁时丢弃迟到的转录输出和进度通知，避免通知异常中断完成或错误处理。修复子进程清理中的空引用异常。这不是新增后台队列功能：Windows 和 Linux 关闭最后一个窗口后仍会退出应用并停止工作。
- 日志显示保留带时间戳的转录行，并单独翻译同一批输出中的状态行。限制状态规则，避免再次翻译显示的文件名和错误详情中的文字。这不会修改保存的 SRT 或实际文件名。
- 设备设为自动时，如果加载模型或创建第一个上下文因GPU相关错误失败，会尝试改用CPU。这与并行失败后在同一GPU上逐条重试不同。应用会记住失败模型，直到显式卸载模型或重启，以免反复尝试GPU。原因会以五种语言显示在已打开的窗口中，无窗口时的通知不会稍后重放。这不表示已验证7B模型在6GB显卡上的性能。
- 更新了五种语言的 DeepL 账户方案说明，并明确离线使用前需要下载模型。
- 应用代码按职责拆分到 `src/`。Windows 包排除 Linux 库和运行时不需要的安装脚本。开发和依赖安装所需的 `scripts/postinstall.js` 保持不变。

## Polski

Aktualizacja poprawia weryfikację pobieranych modeli tłumaczenia lokalnego i obsługę błędów tłumaczenia oraz porządkuje kod aplikacji i pliki pakietu.

- Dodano eksperymentalny tryb Automatyczny, pozostawiając Pojedynczo jako domyślny. Gdy cały model mieści się na GPU CUDA, tryb automatyczny sprawdza wolną pamięć i liczbę napisów. Tłumaczenia bazowej próbki są używane w wyniku, a małe zadania pomijają nieopłacalne pomiary. Porównanie może jednak wydłużyć cały proces. Hy-MT2 1.8B i 7B używają tych samych zasad. Nieudane utworzenie dodatkowego kontekstu lub brak pamięci podczas pracy równoległej przywraca tryb pojedynczy na tym samym GPU. Log pokazuje używany backend, liczbę równoległych zadań i czas. Napisy nie są łączone w jeden prompt, a przyspieszenie nie jest gwarantowane dla każdego zadania.
