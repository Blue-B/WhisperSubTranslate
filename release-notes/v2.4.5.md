## 개요

WhisperSubTranslate v2.4.5 — **UI·안정성 패치 릴리즈**. 릴리즈 후 전체 감사에서 발견된 설정·대기열 UI 결함과 다운로드·취소 경계를 보강했습니다.

## 다운로드

- **Windows 포터블(권장)**: `WhisperSubTranslate-v2.4.5-win-x64.zip`
  → 압축 해제 → `WhisperSubTranslate.exe` 실행
- **Linux/macOS**: 소스에서 직접 실행 (README의 Linux Setup 참조)

## 🔧 수정

- **설정 로드 복구** — 설정 로드 실패 시 이전 값이 비거나 잘못 표시되지 않도록 잠그고, 다시 시도 버튼으로 복구합니다.
- **설정 UI** — 모델 드롭다운을 스크롤해도 뒤의 설정 화면이 함께 움직이지 않습니다. 대기열 패널이 좁을 때 버튼이 줄바꿈되어 제목과 개수가 항상 보입니다.
- **대기열 삭제** — 유휴 상태에서 대기열을 비울 때 "자막 추출 준비 중..." 진행 패널이 잘못 나타나던 문제를 고쳤습니다.
- **로컬 모델 표기** — 번역 방식 목록이 "Hy-MT2 1.8B/7B"로 표시되어, 아래에서 1.8B/7B 모델을 선택한다는 것이 분명해졌습니다.
- **Gemini 모델 목록** — 자막 번역에 실제 사용 가능한 Flash/Pro 텍스트 모델만 표시하고 AQA·Robotics·이미지·오디오·임베딩·에이전트 항목을 제외합니다.
- **대용량 WAV 처리** — RIFF/RF64 검증을 64바이트 헤더로 수행해 전체 파일을 메모리에 올리지 않으며, 기존 WAV 파일은 그대로 보존됩니다.
- **다운로드·취소 안전성** — 첫 다운로드 호출자도 진행률을 받고, 중단된 로컬 모델 다운로드는 이어받기가 가능하며, 번역 중지가 재시도 대기를 즉시 끊습니다.
- **설치 실패 보고** — llama/whisper 설치 실패를 독립적으로 추적하고 redirect 경합과 Sync 디스크 피크 계산을 보강했습니다.

## Overview

WhisperSubTranslate v2.4.5 — **UI and stability patch release**. Fixes settings and queue UI defects found in a post-release audit and hardens download and cancellation boundaries.

## Download

- **Windows Portable (Recommended)**: `WhisperSubTranslate-v2.4.5-win-x64.zip`
  → Extract → Run `WhisperSubTranslate.exe`
- **Linux/macOS**: Run from source (see Linux Setup in README)

## 🔧 Fixed

- **Settings-load recovery** — a failed settings load keeps provider fields locked instead of showing stale or blank values, with a Retry action to restore them.
- **Settings UI** — scrolling the model dropdown no longer moves the settings behind it, and queue actions wrap onto a second row at narrow widths so the queue title and count stay visible.
- **Queue clearing** — clearing the queue while idle no longer reveals a progress panel stuck on "Preparing extraction...".
- **Local model labels** — the translation-method entry now reads "Hy-MT2 1.8B/7B", matching the model sub-selector below.
- **Gemini model list** — the picker shows only general Flash/Pro text models usable for subtitle translation, excluding AQA, Robotics, image, audio, embedding, and managed-agent entries.
- **Large WAV handling** — RIFF/RF64 validation reads a fixed 64-byte header instead of loading the whole file, and existing sibling WAV files are preserved untouched.
- **Download and cancellation safety** — the first download caller receives progress, interrupted local-model downloads stay resumable, and stopping a translation interrupts an active retry delay immediately.
- **Installer failure reporting** — llama and whisper installation failures are tracked independently, with hardened redirect handling and Sync peak-disk calculations.

## 🧪 Validation

- Linux smoke/E2E/interaction tests, i18n, lint, Prettier, `npm audit`, and LSP checks passed
- Windows portable packaging, ASAR synchronization, and live-app checks of queue, dropdown, and label behavior verified
- Real Windows native Sync CPU speech extraction passed
