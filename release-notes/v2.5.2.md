## 한국어

GPU가 여러 개인 PC를 위한 수정과, 앱 종료 시 화면 배율 문제를 고친 패치입니다.

### 변경 사항

- 앱을 닫을 때 Windows의 모든 창 글씨가 잠깐 크게 보였다가 돌아오는 문제를 수정했습니다. 종료 정리 과정에서 실행하던 `nvidia-smi --gpu-reset`이 Windows에서는 모든 GPU의 NVIDIA 디스플레이 드라이버를 재시작하는 명령이었습니다. 이 호출을 제거했으며, 작업 프로세스를 종료하는 것만으로 GPU 메모리는 해제됩니다.
- CUDA GPU가 2개 이상인 PC에서는 처리 장치 목록에 `GPU 0: 이름`, `GPU 1: 이름`처럼 각 GPU가 표시됩니다. 하나를 고르면 음성 인식, 싱크 엔진과 로컬 번역이 그 GPU만 사용합니다. 번호는 `nvidia-smi`에 표시되는 순서와 같고, 선택은 저장되어 다음 실행에도 유지됩니다. 로컬 번역 모델을 이미 불러온 뒤 GPU를 바꾸면 번역에는 앱을 다시 시작한 뒤 반영됩니다.
- 기존 자동, GPU, CPU 선택은 이전과 같게 동작하며, GPU가 1개인 PC에는 새 항목이 표시되지 않습니다. Vulkan으로 동작하는 GPU의 개별 선택은 이번 버전에 포함되지 않습니다.

### 사용 안내

Windows에서는 `WhisperSubTranslate-v2.5.2-win-x64.zip`을 새 폴더에 풀고 `WhisperSubTranslate.exe`를 실행하세요. 기존 포터블 데이터를 옮길 경우 앱을 종료하고 `portable-data` 폴더를 백업한 뒤 복사하세요.

whisper.cpp는 v1.9.1을 유지하며, 엔진과 모델 파일은 바뀌지 않았습니다. GPU 개별 선택은 실제 GPU 2개 환경 대신 GPU 목록을 모의한 앱 실행과 단일 GPU의 whisper.cpp 장치 제한 시험으로 확인했습니다.

## English

A patch for PCs with multiple GPUs and for a screen scaling problem when the app exits.

### Changes

- Fixed all Windows text briefly appearing enlarged when the app closed. Exit cleanup ran `nvidia-smi --gpu-reset`, which on Windows restarts the NVIDIA display driver for every GPU. The call has been removed; ending the app's work processes already releases GPU memory.
- On PCs with two or more CUDA GPUs, the device list shows each GPU as `GPU 0: name`, `GPU 1: name`. Selecting one limits transcription, the sync engine and local translation to that GPU. Numbers follow the `nvidia-smi` order, and the choice is saved for the next launch. If a local translation model is already loaded, restart the app for a new GPU choice to apply to translation.
- Automatic, GPU and CPU work as before, and single-GPU PCs see no new options. Selecting an individual Vulkan GPU is not included in this release.

### Usage

On Windows, extract `WhisperSubTranslate-v2.5.2-win-x64.zip` into a new folder and run `WhisperSubTranslate.exe`. If moving portable data, close the app and back up the `portable-data` folder before copying it.

whisper.cpp remains at v1.9.1, and engine and model files are unchanged. GPU selection was checked with a simulated GPU list in the app and a whisper.cpp device-restriction test on a single GPU, not on a physical two-GPU system.

## Polski

Poprawka dla komputerów z wieloma kartami GPU oraz problemu ze skalowaniem ekranu przy zamykaniu aplikacji.

### Zmiany

- Naprawiono chwilowe powiększanie tekstu we wszystkich oknach Windows po zamknięciu aplikacji. Podczas zamykania aplikacja uruchamiała `nvidia-smi --gpu-reset`, które w Windows restartuje sterownik ekranu NVIDIA dla wszystkich kart. To wywołanie zostało usunięte; zakończenie procesów roboczych wystarcza do zwolnienia pamięci GPU.
- Na komputerach z co najmniej dwiema kartami CUDA lista urządzeń pokazuje każdą kartę jako `GPU 0: nazwa`, `GPU 1: nazwa`. Wybranie jednej ogranicza rozpoznawanie mowy, silnik synchronizacji i tłumaczenie lokalne do tej karty. Numeracja odpowiada kolejności w `nvidia-smi`, a wybór jest zapisywany na następne uruchomienie. Jeśli model tłumaczenia lokalnego jest już załadowany, zmiana karty zadziała w tłumaczeniu po ponownym uruchomieniu aplikacji.
- Opcje Automatycznie, GPU i CPU działają jak dotąd, a na komputerach z jedną kartą nie pojawiają się nowe pozycje. Wybór pojedynczej karty działającej przez Vulkan nie jest częścią tego wydania.

### Użycie

W Windows rozpakuj `WhisperSubTranslate-v2.5.2-win-x64.zip` do nowego folderu i uruchom `WhisperSubTranslate.exe`. Przed przeniesieniem danych przenośnych zamknij aplikację i wykonaj kopię zapasową folderu `portable-data`.

whisper.cpp pozostaje w wersji v1.9.1, a pliki silnika i modeli nie zostały zmienione. Wybór karty sprawdzono w aplikacji z symulowaną listą GPU oraz testem ograniczenia urządzenia whisper.cpp na jednej karcie, a nie na fizycznym zestawie dwóch kart.
