## Overview

WhisperSubTranslate v2.2.1 — **patch release**. Fixes local GPU/CUDA translation silently falling back to CPU because the bundled `node-llama-cpp` CUDA backend shipped without its CUDA runtime DLLs.

## Download

- **Windows Portable (Recommended)**: `WhisperSubTranslate-v2.2.1-win-x64.zip`
  → Extract → Run `WhisperSubTranslate.exe`
- **Linux/macOS**: Run from source (see Linux Setup in README)

---

## 🔧 Fixed

- **CUDA local translation** — `scripts/postinstall.js` installs the cross-platform `node-llama-cpp` binaries with `--ignore-scripts`, so `@node-llama-cpp/win-x64-cuda-ext` never downloaded its CUDA runtime DLLs (`cudart64_12` / `cublas64_12` / `cublasLt64_12`). The packaged `ggml-cuda.dll` could not resolve its imports at runtime and CUDA acceleration silently fell back to Vulkan/CPU, even when the user selected GPU (CUDA). A new electron-builder `afterPack` hook (`scripts/afterPack.js`) copies the CUDA 12 runtime DLLs already bundled with whisper-cpp next to `ggml-cuda.dll` in the packaged app so the CUDA backend can initialize. Windows-only, idempotent, never fails the build.

## Przegląd

WhisperSubTranslate v2.2.1 — **wydanie naprawcze**. Naprawia lokalne tłumaczenie GPU/CUDA po cichu wycofujące się do CPU, ponieważ dołączony backend CUDA `node-llama-cpp` nie zawierał bibliotek DLL środowiska CUDA.

## Pobieranie

- **Windows przenośna (zalecana)**: `WhisperSubTranslate-v2.2.1-win-x64.zip`
  → Rozpakuj → Uruchom `WhisperSubTranslate.exe`
- **Linux/macOS**: Uruchom ze źródeł (patrz Linux Setup w README)

---

## 🔧 Naprawione

- **Lokalne tłumaczenie CUDA** — `scripts/postinstall.js` instaluje binaria `node-llama-cpp` z `--ignore-scripts`, więc `@node-llama-cpp/win-x64-cuda-ext` nigdy nie pobrał bibliotek DLL środowiska CUDA (`cudart64_12` / `cublas64_12` / `cublasLt64_12`). Zapakowany `ggml-cuda.dll` nie mógł rozwiązać importów w czasie działania i akceleracja CUDA po cichu wracała do Vulkan/CPU, nawet gdy wybrano GPU (CUDA). Nowy hak `afterPack` electron-buildera (`scripts/afterPack.js`) kopiuje biblioteki DLL środowiska CUDA 12 (już dołączone do whisper-cpp) obok `ggml-cuda.dll` w zapakowanej aplikacji, aby backend CUDA mógł się zainicjalizować. Tylko Windows, idempotentny, nigdy nie powoduje błędu budowania.

</details>
