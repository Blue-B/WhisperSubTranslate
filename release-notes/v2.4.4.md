## 개요

WhisperSubTranslate v2.4.4 — **안정성 패치 릴리즈**. 번역·다운로드·설정·파일 보존 경계를 강화하고 Windows 실제 음성 추출까지 검증했습니다.

## 다운로드

- **Windows 포터블(권장)**: `WhisperSubTranslate-v2.4.4-win-x64.zip`
  → 압축 해제 → `WhisperSubTranslate.exe` 실행
- **Linux/macOS**: 소스에서 직접 실행 (README의 Linux Setup 참조)

## 🔧 수정

- **번역 언어 전달** — 선택한 원본 언어가 직접 SRT 번역과 영상 추출 후 번역의 모든 API 경로에 전달됩니다. (#44)
- **DeepL 문맥 번역** — 앞뒤 자막 문맥을 DeepL에 전달하고, 문맥별 캐시를 충돌 없이 분리합니다. (#49)
- **DeepL·MyMemory 오류 처리** — :fx 키 힌트, rate limit 분류, 오류 문구가 자막 결과에 기록되지 않는 안전장치를 보강했습니다. (#41, #42, #43, #48)
- **자막 병합과 VAD** — 중복·1ms cue 병합과 VAD 최대 발화 길이 처리를 보강했습니다. (#46, #47)
- **Sync 모델 호환성** — GPU compute type 선택과 CUDA/CPU 폴백을 안정화했습니다. (#45)
- **휴대용 데이터 경로** — `%APPDATA%` 대신 실행 파일 옆 `portable-data/` 또는 환경 변수 경로를 사용할 수 있습니다. (#50)
- **파일·설정 보존** — WAV 백업 실패 시 원본 삭제를 차단하고, 설정 저장 중 입력·비동기 로드·다운로드 취소 경합을 안전하게 처리합니다.
- **다운로드·설치 안전성** — API key와 디스크 공간을 사전 검사하고, Sync 설치의 전체 피크 공간을 계산하며, Windows postinstall redirect와 partial 파일 정리를 보강했습니다.

## 🧪 검증

- Linux 전체 smoke/E2E, i18n, lint, Prettier, `npm audit`, LSP 통과
- Windows native GGML CPU 및 large-v2 Sync 실제 음성 추출 통과
- Windows portable 패키징, CUDA runtime, ffprobe, ASAR 파일 동기화 확인

## Overview

WhisperSubTranslate v2.4.4 — **stability patch release**. Strengthens translation, download, settings, and file-preservation boundaries, with real Windows speech extraction validation.

## Download

- **Windows Portable (Recommended)**: `WhisperSubTranslate-v2.4.4-win-x64.zip`
  → Extract → Run `WhisperSubTranslate.exe`
- **Linux/macOS**: Run from source (see Linux Setup in README)

## 🔧 Fixed

- **Source-language forwarding** — the selected source language now reaches every direct-SRT and post-extraction translation API path. (#44)
- **DeepL context translation** — neighbouring cues are forwarded to DeepL and context-specific cache entries are collision-resistant. (#49)
- **DeepL and MyMemory errors** — improved `:fx` key hints, rate-limit classification, and protection against writing provider error text into subtitle output. (#41, #42, #43, #48)
- **Subtitle merging and VAD** — strengthened duplicate/1 ms cue merging and maximum VAD speech-duration handling. (#46, #47)
- **Sync model compatibility** — stabilized GPU compute-type selection and CUDA/CPU fallback behavior. (#45)
- **Portable data layout** — use `portable-data/` beside the executable or `WHISPER_PORTABLE_DATA` instead of `%APPDATA%`. (#50)
- **File and settings preservation** — failed WAV backups never delete the source, while settings edits, asynchronous loads, and download cancellation races are handled safely.
- **Download and installation safety** — API-key and disk-space preflights, aggregate Sync peak-space checks, Windows postinstall redirect draining, and partial-file cleanup are hardened.

## 🧪 Validation

- Linux smoke/E2E, i18n, lint, Prettier, `npm audit`, and LSP checks passed
- Real Windows GGML CPU and large-v2 Sync speech extraction passed
- Windows portable packaging, CUDA runtime, ffprobe, and ASAR synchronization verified
