## 개요

WhisperSubTranslate v2.5.0은 호환되는 Windows GPU에 Vulkan 가속을 추가하고, 모델과 실행 파일 다운로드의 무결성과 복구 기능을 강화한 기능 릴리스입니다.

## 다운로드

- **Windows 포터블(권장)**: `WhisperSubTranslate-v2.5.0-win-x64.zip`
  압축을 푼 뒤 `WhisperSubTranslate.exe`를 실행하세요.
- **Linux/macOS**: README의 Linux Setup 안내에 따라 소스에서 실행하세요.

## 새 기능

- **Vulkan GPU 가속**: 일반 Whisper GGML 모델에서 호환되는 AMD, Intel, NVIDIA GPU를 사용할 수 있습니다. 자동 모드는 CUDA, Vulkan, CPU 순서로 시도합니다.
- **실제 백엔드 표시**: 장치 상태에서 현재 CUDA, Vulkan, CPU 중 어떤 방식이 선택됐는지 확인할 수 있습니다.
- **모델 폴더 버튼**: 설정에서 앱이 실제로 사용하는 모델 폴더를 바로 열 수 있습니다. 해당 폴더에 수동으로 넣은 모델도 감지합니다.

## 안정성 개선

- 모델, VAD, Sync 파일, whisper.cpp 실행 파일, Vulkan 런타임을 고정된 버전, 크기, SHA-256으로 검증합니다.
- 중단된 다운로드는 `.partial` 파일에서 이어받고, 공식 서버가 차단된 환경에서는 미러로 전환합니다.
- 잘못된 크기, 손상된 해시, 비정상 Range 응답은 설치 완료로 처리하지 않습니다.
- Sync 설치의 디스크 검사는 기존 부분 다운로드와 검증된 엔진 압축 파일을 반영합니다.
- 음성이 없는 영상도 성공 결과가 실제 파일을 가리키도록 빈 SRT를 생성합니다.

## 호환성 안내

- Vulkan 가속은 일반 Whisper 모델에 적용됩니다.
- Sync와 Sync Lite는 기존과 같이 NVIDIA CUDA 또는 CPU를 사용합니다. AMD와 Intel 환경에서는 CPU로 실행됩니다.
- 기존 설정, 모델, 기록, 포터블 데이터 위치는 그대로 유지됩니다.

## 출시 검증

- Windows에서 NVIDIA와 AMD Vulkan 장치로 실제 음성을 SRT로 변환했습니다.
- CPU 실제 전사, Electron E2E, 상호작용 테스트, 다운로드 복구 테스트를 통과했습니다.
- 릴리스 ZIP에는 라이선스와 제3자 고지가 포함되며 SHA-256 체크섬이 함께 제공됩니다.

## Overview

WhisperSubTranslate v2.5.0 adds Vulkan acceleration for compatible Windows GPUs and strengthens the integrity and recovery of model and executable downloads.

## Download

- **Windows Portable (Recommended)**: `WhisperSubTranslate-v2.5.0-win-x64.zip`
  Extract the archive, then run `WhisperSubTranslate.exe`.
- **Linux/macOS**: Run from source by following Linux Setup in the README.

## New features

- **Vulkan GPU acceleration**: normal Whisper GGML models can use compatible AMD, Intel, and NVIDIA GPUs. Automatic mode tries CUDA, then Vulkan, then CPU.
- **Active backend status**: the device panel shows whether CUDA, Vulkan, or CPU was selected.
- **Model-folder button**: Settings can open the exact model directory used by the app. Models placed there manually are detected too.

## Reliability improvements

- Models, VAD, Sync files, whisper.cpp executables, and the Vulkan runtime are checked against pinned versions, sizes, and SHA-256 digests.
- Interrupted downloads resume from `.partial` files and can switch to the mirror when the official endpoint is blocked.
- Wrong sizes, hash mismatches, and invalid byte-range responses cannot be promoted to installed files.
- Sync disk checks account for existing partial downloads and a previously verified engine archive.
- A successful transcription with no speech now creates a real empty SRT instead of returning a missing path.

## Compatibility notes

- Vulkan acceleration applies to normal Whisper models.
- Sync and Sync Lite continue to use NVIDIA CUDA or CPU. They run on CPU on AMD and Intel systems.
- Existing settings, models, history, and portable-data locations remain compatible.

## Release validation

- Real audio was transcribed to SRT on Windows with both NVIDIA and AMD Vulkan devices.
- Real CPU transcription, Electron E2E, interaction tests, and download-recovery tests passed.
- The release ZIP includes license and third-party notices and is published with a SHA-256 checksum.

## Przegląd

WhisperSubTranslate v2.5.0 dodaje akcelerację Vulkan dla zgodnych kart graficznych w Windows oraz wzmacnia weryfikację i wznawianie pobierania modeli i plików wykonywalnych.

## Pobieranie

- **Windows Portable (zalecane)**: `WhisperSubTranslate-v2.5.0-win-x64.zip`
  Rozpakuj archiwum, a następnie uruchom `WhisperSubTranslate.exe`.
- **Linux/macOS**: Uruchom ze źródeł zgodnie z sekcją Linux Setup w README.

## Funkcje

- **Akceleracja GPU Vulkan**: zwykłe modele Whisper GGML mogą korzystać ze zgodnych kart AMD, Intel i NVIDIA. Tryb automatyczny próbuje kolejno CUDA, Vulkan i CPU.
- **Stan aktywnego backendu**: panel urządzenia pokazuje, czy wybrano CUDA, Vulkan, czy CPU.
- **Przycisk folderu modeli**: Ustawienia mogą otworzyć dokładny katalog modeli używany przez aplikację. Ręcznie umieszczone tam modele również są wykrywane.

## Poprawa niezawodności

- Modele, VAD, pliki Sync, pliki wykonywalne whisper.cpp i środowisko Vulkan są sprawdzane według przypiętych wersji, rozmiarów i skrótów SHA-256.
- Przerwane pobieranie jest wznawiane z plików `.partial`, a przy zablokowanym oficjalnym źródle może przełączyć się na źródło lustrzane.
- Nieprawidłowy rozmiar, błędny skrót i nieprawidłowa odpowiedź Range nie mogą zostać uznane za poprawnie zainstalowany plik.
- Kontrola miejsca dla Sync uwzględnia istniejące częściowe pobrania i wcześniej zweryfikowane archiwum silnika.
- Pomyślna transkrypcja materiału bez mowy tworzy rzeczywisty pusty plik SRT zamiast zwracać nieistniejącą ścieżkę.

## Zgodność

- Akceleracja Vulkan dotyczy zwykłych modeli Whisper.
- Sync i Sync Lite nadal korzystają z NVIDIA CUDA lub CPU. Na komputerach z AMD i Intel działają na CPU.
- Istniejące ustawienia, modele, historia i położenie danych przenośnych pozostają zgodne.

## Weryfikacja wydania

- Rzeczywisty dźwięk został przepisany do SRT w Windows na urządzeniach Vulkan firmy NVIDIA i AMD.
- Przeszły testy rzeczywistej transkrypcji CPU, Electron E2E, interakcji oraz odzyskiwania pobierania.
- Archiwum wydania zawiera licencję i informacje o składnikach zewnętrznych oraz jest publikowane z sumą kontrolną SHA-256.
