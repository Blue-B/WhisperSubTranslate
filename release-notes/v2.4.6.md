## 개요

WhisperSubTranslate v2.4.6 — **음성 엔진 안정화 릴리즈**. v2.4.4/v2.4.5에서 "whisper-cli not found" 오류를 겪은 사용자를 위한 업데이트입니다. 음성 엔진을 v2.4.3에서 수천 명이 검증한 바이너리로 되돌리고, 오류 진단과 출시 검증 체계를 강화했습니다.

## 다운로드

- **Windows 포터블(권장)**: `WhisperSubTranslate-v2.4.6-win-x64.zip`
  → 압축 해제 → `WhisperSubTranslate.exe` 실행
- **Linux/macOS**: 소스에서 직접 실행 (README의 Linux Setup 참조)

## 🔧 수정

- **음성 엔진 복원** — 동봉된 whisper.cpp를 v1.9.1로 고정했습니다. v2.4.4부터 실린 새 엔진 빌드는 미서명 신규 바이너리라 일부 백신이 오탐(격리)하여 "whisper-cli not found" 오류가 발생했습니다. v1.9.1은 v2.4.3과 동일한 바이너리로, 7주간 2,000회 이상 다운로드되며 검증되었습니다.
- **실행 실패 진단** — whisper 실행이 막히면 "파일 없음"과 "파일은 있으나 차단됨(백신 격리 등)"을 구분해 실제 원인과 복구 방법을 안내합니다. 오류 로그(`logs/errors.log`)에 정확한 종료 코드가 기록됩니다.
- **복구 안내** — 포터블 배포판 사용자는 whisper.cpp를 수동 다운로드하라는 잘못된 안내 대신, 백신 격리 복원과 폴더 예외 등록 방법을 안내받습니다.

## 🛡 출시 검증 강화

- 릴리스 전에 동봉 엔진으로 **실제 음성 추출 테스트**를 수행하며, 실패하면 게시되지 않습니다.
- 동봉 바이너리를 **VirusTotal(백신 70여 종)로 사전 검사**하여 Microsoft Defender 오탐이 있으면 출시가 중단됩니다.
- 엔진 버전은 고정되며, 새 엔진은 자동 검증 결과가 첨부된 PR 검토 후에만 반영됩니다.

## ℹ️ v2.4.4/v2.4.5에서 오류를 겪었다면

이 버전을 새 폴더에 압축 해제해 실행하세요. 그래도 같은 오류가 나면 Windows 보안 > 보호 기록에서 `whisper-cli.exe` 격리 여부를 확인하고, GitHub 이슈에 `%APPDATA%\whispersubtranslate\logs\errors.log` 파일을 첨부해 주세요. 이제 로그에 정확한 원인이 기록됩니다.

## Overview

WhisperSubTranslate v2.4.6 — **speech-engine stabilization release**. This update is for users who hit the "whisper-cli not found" error on v2.4.4/v2.4.5. It restores the speech engine to the binaries thousands of users validated on v2.4.3 and strengthens error diagnostics and release verification.

## Download

- **Windows Portable (Recommended)**: `WhisperSubTranslate-v2.4.6-win-x64.zip`
  → Extract → Run `WhisperSubTranslate.exe`
- **Linux/macOS**: Run from source (see Linux Setup in README)

## 🔧 Fixed

- **Speech engine restored** — the bundled whisper.cpp is pinned to v1.9.1. The newer engine build shipped since v2.4.4 consisted of fresh unsigned binaries that some antivirus products quarantined as false positives, producing "whisper-cli not found". v1.9.1 is byte-identical to what v2.4.3 shipped, validated by 2,000+ downloads over seven weeks.
- **Launch-failure diagnostics** — when whisper cannot run, the app now distinguishes a genuinely missing binary from one that exists but is blocked (antivirus quarantine and similar), reports the real cause and recovery steps, and records the exact exit code in `logs/errors.log`.
- **Recovery guidance** — portable-build users are guided to restore from antivirus quarantine and add a folder exclusion, instead of the old, incorrect advice to download whisper.cpp manually.

## 🛡 Release verification

- Every release now transcribes a real audio sample with the bundled engine before publishing; a failing engine blocks the release.
- Bundled binaries are pre-scanned on **VirusTotal (70+ engines)**; a Microsoft Defender detection stops the release.
- The engine version is pinned; new engine versions land only through a reviewed pull request carrying automated test results.

## ℹ️ If you hit the error on v2.4.4/v2.4.5

Extract this version into a fresh folder and run it. If the same error still appears, check Windows Security > Protection history for a quarantined `whisper-cli.exe`, and attach `%APPDATA%\whispersubtranslate\logs\errors.log` to a GitHub issue — the log now records the exact cause.

## 🧪 Validation

- Linux smoke/E2E/interaction tests, i18n, lint, Prettier, `npm audit`, and LSP checks passed
- Engine binaries verified byte-identical to the v2.4.3 bundle (44-file CRC comparison)
- Real-transcription and VirusTotal gates passed in the release workflow
